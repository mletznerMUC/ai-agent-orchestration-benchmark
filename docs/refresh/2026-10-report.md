# Refresh round 2026-10

Researched 2026-10-02. Thirteen per-tool researchers plus one market scout,
all dispatched in parallel and all reported back. Every tool key in
`data/tools.json` was checked; no subset, no skips.

The trailing-90-day window for all Maturity re-derivations this round is
**2026-07-04 → 2026-10-02**. That window slide is the story of the round:
three scores moved, and all three moved because of where the window boundary
now falls, not because any vendor shipped or withdrew a capability.

**Three scores moved. Ten held.** Maestro 83 → 85, LangGraph 81 → 79,
Claude Squad 56 → 51.

## 4. Source disagreements

Surfaced, not resolved.

1. **ms-agent — how many model providers?** The open question ADR-005's
   2026-09-02 amendment explicitly left open is still open, and now better
   characterised: the disagreement is *within a single dated vendor page*, not
   between sources. <https://learn.microsoft.com/en-us/agent-framework/integrations/by-component/model-providers/>
   (updated 2026-09-29) yields **12** in its cross-language comparison table,
   **9** in its .NET list, **10** in its Python list and **4** in its Go table;
   a sibling page of the same date yields a fifth count, **9** at ecosystem
   level but a different nine. The published label says "6 Providers", which
   matches none of them. The tier (`yes`) is unaffected at any count. This
   needs a published counting rule, not more research — a researcher cannot
   pick one without inventing the rule.

2. **claude-sdk — when was the billing plan paused?** `price.note` says
   "Jul 2026"; the vendor support article says the pause took effect
   **June 15, 2026**, and no July date appears in any vendor source. Not
   applied — the researcher declined to propose a fix and the origin of
   "Jul 2026" is unknown. Likely a transcription error for "Jun 2026", but
   that is a guess, and a guess is not a source.

3. **openai-sdk — which model does the row name?** `price.rows[2]` says
   "GPT-5.6 API". OpenAI's current catalog has moved to the GPT-6 family
   (GPT-6 Astra 2026-09-03; GPT-6 Sol and Luna 2026-09-22). But the Agents
   SDK's own model docs still name `gpt-5.6-luna` as the SDK's built-in
   default. So the row is stale against the vendor catalog and accurate
   against the SDK default, depending on what it is meant to describe. Not
   resolved here.

4. **openai-sdk — PyPI lags GitHub.** PyPI showed 0.22.3 as latest while the
   GitHub tag was v0.23.0 (2026-10-02). Tier-A tagged releases were used.
   Noted; affects no criterion.

5. **databricks — a release note dated in the future.** The October 2026
   release-notes page returned an entry dated **2026-10-05**, three days after
   the check date. Treated as a fetch anomaly and **not used as evidence**;
   September data alone establishes recency and cadence. Recorded because a
   silently-accepted future-dated source is how bad data enters.

6. **databricks — the Supervisor GA/Beta conflict is resolved.** The prior
   round flagged `price.rows[0]` "Supervisor Agent (GA)" against a doc page
   labelled Beta. The current supervisor page (updated 2026-09-11) no longer
   carries a page-level Beta label, and the overview page (updated 2026-09-30)
   lists Supervisor Agent with no status badge while badging others. The price
   row and the docs now agree. Closing this one out.
