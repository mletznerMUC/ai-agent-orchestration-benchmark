# Refresh round 2026-11

Researched 2026-11-01. Thirteen tools, one researcher each, plus one
market scout — all dispatched in parallel and all reported. Trailing
90-day window for every maturity criterion this round: **2026-08-03 to
2026-11-01**.

Two scores moved, both on `sustained-cadence`, both because releases
landed rather than because anything was re-judged. One criterion is
held deliberately and is the round's single open question (Maestro
`ga-status`, below).

## 1. Data changes, by tool

### maestro — score 85 → 88

| Field | Old | New | Source |
| --- | --- | --- | --- |
| `score.value` | 85 | 88 | derived |
| `score.exact` | 85.0 | 87.5 | derived |
| `rubric.maturity.criteria.sustained-cadence.score` | 1 | 2 | https://github.com/RunMaestro/Maestro/releases |
| `rubric.maturity.raw` / `.points` | 4/6, 10.0 | 5/6, 12.5 | derived |
| `rubric.maturity.evidence` | (2026-10-02 text) | rewritten | as above |
| `release-recency.source` | tag/v0.17.5 | tag/v1.0.2 | https://github.com/RunMaestro/Maestro/releases/tag/v1.0.2 |

**Reasoning.** `sustained-cadence` tier 2 is ">= 6 stable releases in
trailing 90 days". Eight stable tags fall in the window: v0.17.4
(09-21), v0.17.5 (09-25), v0.17.6 (10-04), v0.17.7 (10-04), v0.17.8
(10-05), v1.0.0 (10-09), v1.0.1 (10-20), v1.0.2 (10-21). The four
RC tags in the same window (v0.18.6/7/8-RC, v1.1.0-RC) are
GitHub-flagged pre-releases and are excluded. Arithmetic: 25.0 + 10.0
+ 15.0 + 15.0 + 10.0 + 12.5 = 87.5, which rounds half-up to 88.

**`ga-status` held at 1 — the round's one open question.** The
researcher proposed 1 → 2 (which would make the overall **90**) on the
grounds that Maestro shipped v1.0.0 on 2026-10-09 and tier 2 reads
"major >= 1". That fact is sourced and not in dispute. The reason it
was not applied: tier 1 reads "pre-1.0, **or GA with beta components**",
and the README still lists Copilot-CLI as beta. Maestro now sits in the
overlap between the two tiers, and ADR-005's table does not say which
clause wins. Two things make this a human call rather than a triage
call:

- The 2026-10-02 check cited that same Copilot-CLI beta as part of its
  own tier-1 reasoning, so adopting the researcher's reading reverses a
  prior round's interpretation, not just its facts.
- Databricks is held at `ga-status` 1 today on the "GA with beta
  components" clause. Whichever way this is read binds that entry too,
  and CLAUDE.md rule 2 requires a new scoring interpretation to be
  written down and applied to every tool, not to the one that provoked
  it.

A defensible reading exists in each direction — tier 2 has two routes
(major >= 1, or GA-in-docs), and tier 1's beta clause may be intended to
qualify only the second, in which case Maestro goes to 2 and Databricks
stays at 1 with no inconsistency. That reading may well be right. It is
an ADR, not a data refresh. Held at 1, understating by 2 points, pending
a ruling.

## 4. Source disagreements and open label questions

Surfaced, not resolved.

1. **LangGraph LangSmith Plus: currency.** The site says `~€39/mo.`;
   https://www.langchain.com/pricing says **$39 per seat per month**.
   The numeral matches, the currency does not, and the vendor figure is
   per-seat where the site's label is not. No ADR governs currency
   convention for the price rows (ADR-004 is about this project's own
   cost ledger, not benchmark pricing), so this is a site-wide editorial
   decision, not a data fix. The row is unchanged and still
   `legacy-unsourced`.

2. **Strands AgentCore Runtime: the row is now half the price table.**
   AWS publishes two microVM tiers — v1 at `$0.0895/vCPU-hr` +
   `$0.00945/GB-hr`, and v2 at `0.1276/vCPU-hr` + `$0.0169/GB-hr` — plus
   a committed-baseline rate "launching by October 2026" with no figure
   fixed. The page labels neither tier default nor deprecated and does
   not say whether v1 remains open to new customers. The stored value is
   still accurate for v1 but no longer represents the published pricing.
   Whether to show v2, both, or annotate v1 as legacy is a human call.

3. **Databricks Supervisor Agent is now labelled "legacy" by the
   vendor.** The multi-agent supervisor page (updated 2026-10-14) reads:
   "Supervisor Agent is a legacy offering and is not recommended for new
   systems. For new low-code agents, use Genie Agents." ADR-005's
   `ga-status` tiers have no "legacy" bucket, so the criterion did not
   move — but the matrix cells `multi-agent-parallel` ("Supervisor") and
   `group-chat` ("Supervisor Pattern") both rest on that feature. Both
   are `legacy-unsourced`, so neither can move without a sourcing pass.
   This is the strongest candidate for next round's attention.

4. **Databricks "Unity Gateway" vs "Unity AI Gateway".** Both names
   appear across current docs. No page documents a rename. The matrix
   label says "Unity AI Gateway"; the tier is unaffected.

5. **n8n `price.note` may overstate the trial limit.** The note reads
   "Self-hosted Free · Cloud 14-day trial only", but the pricing page
   shows Starter and Pro as ongoing paid Cloud subscriptions, with the
   explicit "14 days" language attaching to the self-hosted Business
   plan. The note carries no `source`/`checked` of its own, so there is
   no baseline to diff against. Flagged, not changed.

6. **manus-ai `cli-cicd` label says "API (Beta)".** The current API docs
   are versioned (v2 current, v1 deprecated) and the word "Beta" does
   not appear. The capability still reads as `partial`, so the state is
   unaffected — a label-accuracy question, like the open `ms-agent`
   "6 Providers" item in ADR-005.

7. **manus-ai has tiers the site does not show.** A second Pro price
   point ($40/mo, 8,000 credits) sits alongside the $20 entry under the
   same name, and a Team plan (4,000 credits per seat, pooled) exists at
   https://manus.im/team with no row on the site at all. "From $20/mo."
   remains accurate. Adding rows is a presentation decision, not a
   correction.

8. **manus-ai Enterprise row could now be sourced without changing.**
   https://manus.im/team confirms an Enterprise tier above Team with no
   published price, consistent with the existing "Custom". Left
   `legacy-unsourced` — attaching a citation to an unchanged value is
   outside "apply only sourced changes", and ADR-002 expects that gap to
   close when the value moves. Noted so the next round can take it.

## 5. Radar candidates

Two candidates cleared the scout's bars. **Neither has been added to
`data/tools.json`** — adding a tool means scoring it against every
published criterion, which is `/feature` work behind the plan-approval
gate, not a data refresh.

### Candidate 1 — Agent Squad

- **Home:** https://github.com/2fastlabs/agent-squad
- **What it is:** open-source framework that routes a query to the most
  suitable of several specialist agents, with a `SupervisorAgent` that
  delegates to and parallel-queries sub-agents and combines results.
  Python, TypeScript and Swift runtimes.
- **Why it is in category:** classifier-based routing, delegation and
  parallel sub-agent execution are the product, not an add-on.
- **Evidence:** releases `typescript/1.1.5` and `python/1.1.4`, 23 Sep;
  Apache-2.0; 7.8k stars, 744 forks, 1,280 commits per the repo.
- **Unresolved:** the project moved `awslabs/agent-squad` →
  `2fastlabs/agent-squad`. The README confirms the move and the prior
  AWS Labs hosting but gives no reason, and no page states whether AWS
  retains any formal role. Worth settling before evaluation. The release
  year is not printed on the page and was inferred from context.

### Candidate 2 — Relevance AI "Workforce"

- **Home:** https://relevanceai.com/
- **What it is:** proprietary no-code platform where a manager agent
  coordinates a canvas of specialist agents that hand off work to each
  other, with per-agent cost and activity monitoring.
- **Why it is in category:** manager-agent delegation and inter-agent
  handoff are the platform's stated orchestration primitive.
- **Evidence:** vendor changelog with dated entries through 2026-09-03
  (https://relevanceai.com/changelog). Pricing page shows a sales-led
  Enterprise tier only.
- **Unresolved:** adoption figures (40,000 agents/month, SOC 2 Type II,
  named customers) come from secondary coverage, not a primary page.
  Self-serve pricing was not confirmed from a vendor page. Closed
  source, so sovereignty criteria would need separate verification.
