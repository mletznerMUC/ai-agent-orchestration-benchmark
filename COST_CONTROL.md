## What this number is

Token usage recorded in this project's Claude Code session transcripts, valued at
the published Claude API list prices in [`data/model-pricing.json`](data/model-pricing.json).

It is an **estimate of consumption, not an invoice**. Three reasons it can differ
from what Anthropic bills:

1. Sessions run under a Claude subscription are not billed per token at all. For
   those, read this as "what this work would have cost on the API".
2. Negotiated discounts, credits, and partner-platform (Bedrock, Google Cloud)
   rates are not modelled.
3. Runs with no local transcript are missing unless recorded manually — see
   [Coverage](#coverage) below.

## Coverage

What this ledger sees, and what it does not:

- **Covered:** every Claude Code session for this project whose transcript has
  been read by `npm run cost` on the machine that ran it, including each subagent
  run (`researcher`, `scout`, `planner`, `implementer`, `reviewer`, …), because
  subagents write their own transcripts. Each session's priced requests are
  committed under [`data/cost-ledger/`](data/cost-ledger/), so this file can be
  regenerated from any checkout — a session is missing only until the machine
  that ran it has run `npm run cost` once and committed the result.
- **Not covered automatically:** runs that leave no transcript anywhere — the
  scheduled `refresh-research` and `apply` GitHub Actions runs, which call
  `anthropics/claude-code-action` with a real API key. These are genuine API
  spend and are the largest known gap.
- **How to close it:** record them in `data/cost-ci-runs.json` as an array of
  entries; the next `npm run cost`, on any machine, prices them alongside.

```json
[
  {
    "date": "2026-08-01",
    "agent": "refresh-research (CI)",
    "branch": "refresh/2026-08",
    "model": "claude-opus-5",
    "input_tokens": 0,
    "output_tokens": 0,
    "cache_write_5m_tokens": 0,
    "cache_read_tokens": 0,
    "web_search_requests": 0,
    "source": "gh run view <run-id>"
  }
]
```

17 manually recorded run(s) from `data/cost-ci-runs.json` are included above,
alongside 9 session(s) from `data/cost-ledger/`.

**Unpriced models:** claude-opus-5-5, <synthetic> — used but missing from
`data/model-pricing.json`, so their requests count in the token columns and
contribute $0.00 to every cost column (194 request(s)). Add the rate,
with its source, to fix the understatement.

Two further limits worth stating: a request is attributed to the branch checked
out when it ran, so work done on `main` before branching lands under `main`; and
cache-write tokens from older transcripts that report no TTL split are priced at
the cheaper 5-minute rate, which understates rather than inflates.
